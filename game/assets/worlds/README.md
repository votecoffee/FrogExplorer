The 16 reviewed city/landmark runtime tile packs are included in Git. Only each
active pack's manifest, baked meshes/collision and shared textures/materials are
published. Original full-scene GLBs, intermediate glTF buffers, downloads and
obsolete tile packs remain local. See ASSET_CREDITS.md, docs/TILING.md and
config/runtime_assets.lock.json. Device qualifications still apply; bundling
these packs does not establish Linux/Pi performance or gameplay acceptance.
